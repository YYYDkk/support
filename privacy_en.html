Contact Information

### 1. Scope and Purpose of Information Collection

Our Application only collects the contact information list in your device (including basic information such as contact names and phone numbers) when you actively use the core function "Contact Backup and Restore". The purpose of collection is unique and clear: solely to back up contact information to an external storage device designated by you (such as a Type-C mobile hard disk, USB flash drive, etc.), or to restore contacts from a backed-up external storage device to your device. There are no other usage scenarios.

### 2. Authorization Method and User Control Rights

1. Active Authorization Prompt: Before using the "Contact Backup and Restore" function, the Application will pop up a system permission authorization window (prompting "Allow/Deny access to contacts"), clearly informing you of the purpose of the permission. There are no silent applications, forced authorizations, or similar behaviors;
2. Right to Independent Choice: You can freely choose to "Allow" or "Deny" the authorization. If you choose "Deny", only the "Contact Backup and Restore" function will be unavailable. All other important functions of the Application (such as file backup, photo album backup, device management, etc.) can operate normally without affecting your core user experience;
3. Re-authorization Path: If you have denied the authorization, when you attempt to use the "Contact Backup and Restore" function again later, the Application will pop up the authorization prompt again; you can also manually enable or disable this permission through the path "Settings > Apps > NewHub > Permissions > Contacts" on your mobile phone. The permission status will take effect in real time.

### 3. Data Security and Compliance Commitments

1. No Additional Collection: Except for the contact information collected when you actively trigger the "Contact Backup and Restore" function, the Application will not automatically scan or silently collect your contact information in the background, nor will it collect other personal information unrelated to this function (such as device identifiers, location information, etc.);
2. No Data Sharing/Leakage: We will not sell, lease, share, or provide your contact information to any third parties (including advertisers, data analysis institutions, partners, etc.) in any form. Backup data of contacts is only stored on the external storage device designated by you and will not be uploaded to the Application's cloud server;
3. Ownership and Control of Data: You have full ownership and management rights over the backed-up contact data. You can view, modify, or delete the backed-up contact information at any time through the Application or the external storage device. The Application will not interfere with or retain any copies of the backup data.

Management of All File Information

1. Scope and Purpose of Collection

The core functions of our Application are "Mobile Phone Backup" and "Photo Album Backup". We only collect file information explicitly selected by you in your device when you actively use these two functions. Specifically including:
1. Media files: Pictures, videos, and music files in the photo album;
2. Non-media files: Documents (Word/Excel/PDF, etc.), compressed packages, installation packages, and other full-type files selected by you for backup.
The scope of collection is strictly limited to the files or directories explicitly checked by you. We will not automatically scan or collect unauthorized file information in the device. All file information is only used to realize the core function of "backing up to an external storage device (such as a Type-C mobile hard disk, USB flash drive, etc.)" and has no other purposes.

2. Authorization Method and User Control Rights

1. Permission Application Prompt: Before using the "Mobile Phone Backup" and "Photo Album Backup" functions, the Application will pop up a system permission authorization window (prompting "Allow/Deny access to all files"), clearly informing you of the purpose of the permission. There are no silent applications, forced authorizations, or similar behaviors;
2. Right to Independent Choice: You can freely choose to "Allow" or "Deny" the authorization. If you choose "Deny", only the normal use of the "Mobile Phone Backup" and "Photo Album Backup" functions will be affected. Other non-core functions of the Application (such as viewing the list of backed-up files, device connection management, etc.) can operate normally;
3. Re-authorization Path: If you have denied the authorization, when you reuse the backup function later, the Application will pop up the authorization prompt again; you can also manually enable or disable this permission through the path "Settings > Apps > NewHub > Permissions" on your mobile phone. The permission status will take effect in real time.

3. Explanation of the Necessity of Permission

Our Application applies for the "MANAGE_EXTERNAL_STORAGE" permission because the core functions need to support the backup and management of full-type files (including non-media files). Alternative solutions such as the MediaStore API can only access media files such as pictures, videos, and audio, and cannot cover the backup needs of non-media files such as documents and compressed packages. If this permission is removed, the core functions of "Mobile Phone Backup" and "Photo Album Backup" will not be realized, and your full backup needs cannot be met.

4. Data Security and Compliance Commitments

1. No Additional Collection: Except for the file information you actively select for backup, the Application will not collect or store system files in the device, files in the private directories of other applications, or personal information unrelated to the backup function (such as device identifiers, location information, etc.);
2. No Data Sharing/Leakage: We will not sell, lease, share, or provide your file information to any third parties (including advertisers, data analysis institutions, etc.) in any form, nor will we upload file information to the cloud server. All backup files are only stored on the external storage device designated by you;
3. Restrictions on Permission Use: This permission is only used when you actively trigger a backup operation. After the operation is completed, file access will be terminated immediately. There is no behavior of continuously accessing or scanning files in the background;
4. Ownership and Control of Data: You have full ownership and management rights over all backup files. You can delete or modify backup files at any time through the Application or external devices. The Application will not interfere with or retain any copies of the files.
